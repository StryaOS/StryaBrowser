# StryaBrowser
StryaOSのブラウザアプリです。
StryaOS以外にもDebianベースOSにも入ります。
---
# 仕様
- Electronベース
- StryaOS向け（Debian）
- Chromium 156互換
---
# ビルド＆起動
Bashで
```bash
npm start
```
で起動します
Bashで
```bash
npm run build:deb
```
でLinuxDebファイルを生成してビルドできます

---
# Windows番について
頑張ればWindowsビルドも作れますがここでは紹介しません。
